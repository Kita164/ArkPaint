# ArkPaint · 拼豆自动绘图

ArkPaint 是一款面向 **MuMu 模拟器** 的桌面工具：把任意图片变成游戏可用的 **24×24 像素稿**，再通过 **ADB** 在拼豆玩法中自动选色、填格。

仓库地址：[https://github.com/luojingfeng164/ArkPaint](https://github.com/luojingfeng164/ArkPaint)

---

## 下载与使用（推荐普通用户）

不想自己编译时，请到仓库的 **[Releases](https://github.com/luojingfeng164/ArkPaint/releases)** 页面下载已构建好的压缩包（例如 `ArkPaint-windows-x64.zip`），解压后运行 `ArkPaint.exe`。

| 需求 | 去哪里拿 |
|------|----------|
| 直接使用程序 | **Releases** 里的 zip / exe 附件 |
| 查看或修改源码 | **Code → main 分支**（或 `git clone`） |

> 可执行文件体积较大，**不会**放进 `main` 源码树；每次发版在 Releases 上传一份即可。

MuMu 12 常见 ADB：`127.0.0.1:16384`（多开端口按 +32 递增）。

---

## 能做什么

| 能力 | 说明 |
|------|------|
| 图片转像素 | 导入本地图 / 拖入文件 / 框选屏幕截图，自动映射到游戏色盘（约 40 色） |
| 手动微调 | 在 24×24 画布上涂色、吸取、撤回；支持滚轮放大与边缘平移 |
| 对照预览 | 左侧同时显示「原图」和「当前像素效果」缩略图，方便边改边看 |
| 连接模拟器 | 自动查找 MuMu 的 `adb.exe`，支持自定义端口与多开端口扫描 |
| 校准与识别 | 一键完成画布/颜料栏校准，并检查是否处于拼豆编辑页 |
| 自动绘制 | 按颜色分组填格，进度条显示当前色、色块进度、已填/总格数 |
| 导出成品 | 将画好的像素图导出为 PNG / JPEG |

## 界面布局

```
┌─────────────┬──────────────────────┬─────────────┐
│ 左侧        │ 中间画板              │ 右侧        │
│ 导入图片    │ 24×24 像素画布        │ 颜料色盘    │
│ 原图预览    │ 撤回 / 导出 / 编号开关 │ 校准并识别  │
│ 像素预览    │ 滚轮缩放 · 边缘平移   │ 进度条      │
│ 连接设置    │                      │ 开始/停止   │
│ 绘制参数    │                      │             │
└─────────────┴──────────────────────┴─────────────┘
```

### 左侧：素材与连接

- **导入图片**：选择文件，或把图片拖进预览区  
- **截图**：隐藏本窗口后，在屏幕上 **拖拽框选** 区域，再转为像素图（非整屏硬截）  
- **原图预览**：浅色底，对照导入内容  
- **像素预览**：实时反映画板当前效果  
- **连接设置**  
  - 主机、ADB 端口（可手填）  
  - MuMu 多开提示：`0号 16384`，之后每个实例 **+32**（1号 16416、2号 16448…）  
  - `adb.exe` 路径可浏览选择；常见路径如  
    `%USERPROFILE%\Netease\MuMuPlayer-12.0\shell\adb.exe`  
  - **自动检测** adb、**连接模拟器**（会尝试用户端口及常见多开端口；成功会提示如「0号 16384」）  
- **绘制参数**：识别置信度、点击间隔、是否跳过白色格  

### 中间：像素画板

- 左键涂色、右键吸取、拖拽连续填色  
- **撤回**（`Ctrl+Z`）：按笔划撤销  
- **导出**：输出放大后的像素图（默认约 768×768，无编号）  
- **编号**开关：胶囊式浅色开关，控制格子与色盘上的色号显示  
- **滚轮缩放**：默认铺满为最小，不可再缩小；放大后鼠标移到画板边缘会自动平移  

### 右侧：色盘与自动绘制

- 颜料栏：点击选色，绘制时高亮当前色  
- **校准并识别**：依次打开校准向导 → 自动识别拼豆画面  
- **开始绘图 / 停止**：同一按钮复用；绘制中显示进度（当前色、色块序号、已填/总数等）

## 推荐使用流程

1. **准备像素稿**  
   导入图片，或框选截图 → 在画布上微调 → 需要时点「导出」备份  
2. **连接模拟器**  
   打开 MuMu 与游戏拼豆编辑页 → 自动检测 / 连接 ADB  
3. **校准**  
   点「校准并识别」，按提示点画布四角与颜料位置（分辨率或窗口变化后请重做）  
4. **开始绘图**  
   确认在拼豆编辑页 → 点「开始绘图」；中途可点同一按钮「停止」  

> 每次重新连接 ADB 后，首次开始绘制前会要求再走一遍校准，避免坐标偏移。

    AdbWinUsbApi.dll

## 开发运行

环境：**Python 3.10+**（推荐 3.13）

```bash
git clone https://github.com/luojingfeng164/ArkPaint.git
cd ArkPaint

python -m venv .venv313
# Windows:
.venv313\Scripts\activate
pip install -r requirements.txt
.venv313\Scripts\python.exe main.py
```

主要依赖：`PySide6`、`Pillow`、`numpy`、`opencv-python-headless`、`pyinstaller`。

## 说明与限制

- 色盘默认按游戏顺序约 **40** 色；校准保存时可采样可见色刷新 RGB。  
- 默认可跳过白色格，减少无效点击。  
- 自动绘制依赖校准坐标与稳定的拼豆编辑界面；游戏 UI 大改时需重新校准。  
- 本工具通过 ADB 模拟点击，请在自有账号 / 合规场景下使用。
